# 错误反馈与按需原始日志读取摘要

日期：2026-10-30。范围：源码实现、纯离线回归和资产保护；不包含真实容器、付费生成或官方独立判分。

## 改变后的行为

- 新增 `swe_repair.feedback`，从公开生成输出中确定性选择异常、断言、堆栈/源码位置及输出尾部；保留原始源码行号和异常值，并标明原日志行位置。证据默认最多 2400 字符，单条错误反馈最多 3000 字符，无额外模型摘要调用。
- `FailureRecord.raw_output` 保存实际捕获的完整文本；原指纹、错误分类和路由规则不变。语法检查移除原有的 300 字符提前截断。这里保存的是进程实际捕获的文本，不承诺恢复进程未输出或因中断未捕获的内容。
- 前缀进入交互及固定延续均使用 `prompt_view()`：包含命令、退出码、错误类型、候选关联、关键证据、日志 ID 和行数，排除原始输出全文。旧快照没有 raw_output 时明确显示原始日志不可用。
- 交互内补丁验证和追加公开检查均使用相同摘要器；失败不再仅向下一轮传入日志开头。追加公开检查的日志保存在 `FailureLog.tool_records`，单独审计，不改变原有候选选择、环境恢复和路由失败历史。
- 复用 `read_region`，六种工具不变。模型使用 `path="log:<sha256>"`、1-based start/end 和可选 offset 读取原始输出；offset 是首行中的字符偏移。每页最多 3000 字符、120 行，返回下一页游标，支持完整读取超长单行。
- 日志引用仅在本分支的失败记录及追加检查日志中解析，不能读取宿主路径、任意容器文件、其他分支新日志或评测器文件。继承的前缀日志可在分支新容器中直接读取，无需重新运行测试。
- 读取日志仍消耗会话具名工具次数，文本进入后续请求后计入模型输入预算；不产生 container exec，不新增付费摘要调用，不放宽全局资源和金额守卫。
- 提示版本更新为 `proposal_v1_error_feedback_20261030`；配置仍为 draft/pending，live_authorized=false。
