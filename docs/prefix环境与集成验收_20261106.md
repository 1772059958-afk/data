## 源码与入口

- `scripts/run_cf.py --mode prefix` 保留生成白名单、累计四元资源预算、单实例/批次金额守卫、实际镜像及 base commit 检查、候选验证与原始日志，在前缀快照完成后退出。输出组为 `PREFIX`，不运行路由、固定/交互延续或独立 B。
- 失败和前缀预算停止仍保留候选、成本、错误状态及终止原因。独立判分的身份校验支持 PREFIX；正式/配对分析拒绝把 prefix-only 记录当成正式方法结果。
- `scripts/probe_model.py` 默认只打印计划，显式执行需要独立授权，限一次真实请求、256 输出 token、0.05 CNY、零重试，保存 usage、模型响应标识与保守失败预留。响应没有 model 字段时不使用请求别名伪造观测身份。
- 专用 `configs/prefix_smoke_20261106.json` 约束 dev、指定实例、数量 1 和 prefix 模式。主配置 `configs/proposal_v1.json` 保持 draft/pending、live_authorized=false；没有伪造路由校准或正式冻结。
- 用户指定 project_dotenv 后，两个入口都只读取项目 `.env` 的 `DEEPSEEK_API_KEY`，不回退到系统 Key。文件由 Git 忽略，任何日志或配置均不保存 Key。
